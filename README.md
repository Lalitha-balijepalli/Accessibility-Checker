# AccessAlly AI – AI‑Based Website Accessibility Checker

## 🚀 Project Overview

**AccessAlly AI** is a web‑based accessibility auditing tool that helps developers and organizations identify and fix accessibility issues in websites. The application scans a given website URL, checks it against **WCAG accessibility guidelines**, and provides **AI‑powered explanations, severity classification, and improvement suggestions**.

This project was **designed and built end‑to‑end by me** as a real‑world solution to promote inclusive and accessible web design.

🔗 **Live Demo:** [https://accessally-ai.netlify.app/](https://accessally-ai.netlify.app/)

---

## 🎯 Problem Statement

Many websites fail to meet accessibility standards, making them difficult to use for people with disabilities. Developers often lack clear guidance on:

* What accessibility issues exist
* Why they matter
* How to fix them correctly

**AccessAlly AI** solves this by combining automated accessibility checks with **AI‑generated explanations and fixes**.

---

## ✨ Key Features

### 🔍 Website Accessibility Audit

* Scan any public website using its URL
* Detect common accessibility issues automatically

### 📏 WCAG Compliance Checking

* Issues mapped to **WCAG guidelines** (A / AA / AAA)
* Examples:

  * Missing H1 heading
  * Missing form labels
  * Non‑descriptive icons
  * Improper semantic structure

### ⚠️ Severity Classification

* Issues categorized as:

  * 🔴 Critical
  * 🟠 Moderate
  * 🔵 Minor

### 📊 Accessibility Score

* Generates an overall accessibility score (0–100)
* Visual score indicator for quick understanding

### 🤖 AI‑Powered Explanations

* Clear, human‑readable explanation for each issue
* Explains how the issue impacts screen readers and assistive technologies

### 🛠️ AI Fix Recommendations

* Practical suggestions to fix accessibility issues
* Developer‑friendly guidance aligned with best practices

### 📄 Downloadable Audit Report

* Generate and download accessibility reports as PDF

### 🧑‍💻 Developer‑Friendly Dashboard

* Clean UI
* Filters by severity and WCAG level
* Easy navigation and issue review

## 🧠 How It Works

1. User enters a website URL
2. The system scans the website structure
3. Accessibility issues are detected based on WCAG rules
4. Issues are classified by severity
5. AI generates explanations and fix suggestions
6. Accessibility score is calculated
7. Results are displayed on a dashboard
8. User can download the audit report
